**Refined Abstract:**
Academic integrity is a growing concern in remote and large-scale examination environments. Traditional manual proctoring is resource-intensive and subjective, while current automated systems often suffer from high false-positive rates and opaque decision-making. We present MulTiCheat, an AI-based multimodal cheating detection system. By fusing deep learning models—specifically YOLOv8 for unauthorized object detection and YOLOv8-pose for kinematic behavior analysis—MulTiCheat accurately identifies suspicious activities such as phone usage, unauthorized notes, and anomalous gaze patterns. A novel temporal sliding-window aggregator filters out sporadic anomalies, drastically reducing false positives. Evaluated on synthetic examination scenarios, the system achieved a 91.2% precision rate. Furthermore, MulTiCheat introduces an interactive web-based dashboard, enabling examiners to seamlessly navigate flagged events via a synchronized playback timeline and annotated evidence galleries, thereby streamlining the verification process.

**Refined Conclusion:**
This paper demonstrated the design and implementation of MulTiCheat, a robust, privacy-conscious, and scalable exam monitoring system. By decoupling heavy computer vision pipelines into an asynchronous backend and shifting result visualization to an interactive web client, the system overcomes the computational and usability bottlenecks of legacy proctoring software. The integration of state-of-the-art YOLOv8 models allowed for precise multimodal fusion, reducing false positives through intelligent temporal aggregation. Future iterations will focus on incorporating audio anomaly detection and expanding parallel processing capabilities for deployment across large institutional networks.
